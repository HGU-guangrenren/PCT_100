化工控制实训装置

PCT_100_CTL 是一款面向化工实训场景的智能控制器，集成传感器采集、继电器控制、WiFi 配网与 MQTT 远程通信，可灵活切换自动/手动控制模式，满足教学实训与科研验证需求。

Overview

产品概述

PCT_100_CTL 基于 ESP32 微控制器，集成了多路传感器与执行器，支持本地自动控制与远程云端管理，适用于化工控制类课程的实训教学。

⚙️

双模式控制

支持 AUTO（自动阈值控制）与 MANUAL（手动循环切换）两种模式，KEY2 长按即可切换，灵活应对不同实训场景。

📡

WiFi 配网

提供三种配网模式：静态写死、串口扫描选网、Flash 保存自动重连。高级模式可自动保存凭据，掉电不丢失。

☁️

MQTT 远程通信

通过 MQTT 协议与云端 Broker 通信，支持远程控制继电器、切换模式、设置阈值、远程重启等，LWT 遗嘱机制实时感知设备在线状态。

🌡️

多传感器融合

集成 DS18B20 数字温度传感器与光敏电阻 ADC 采集，实时监测环境温度与光照强度，自动触发风扇/灯光执行动作。

🖥️

OLED 显示

0.96 寸 SH1106 OLED 显示屏（I2C 接口），实时显示模式、光照、温度、网络状态和继电器状态等运行信息。

💡

RGB 状态指示灯

WS2812 万色灯珠，通过 6 种颜色与呼吸动画指示设备运行状态：正常/报警/WiFi 断连/MQTT 断连等，一目了然。

Architecture

系统架构

传感器采集数据 → ESP32 主控逻辑处理 → 执行器响应 & 云端同步，完整的物联网闭环控制架构。

Features

功能特性

详细功能说明，涵盖硬件接口、控制逻辑与通信协议。

01

按键控制逻辑

KEY1 自锁开关直读物理状态作为总闸，KEY2 支持短按与长按两种操作。

  • KEY1 闭合 → power_on()，断开 → power_off()
  • KEY2 短按（<1s）→ 手动模式循环切换（灯→风扇→全开→全关）
  • KEY2 长按（≥1s）→ 切换 AUTO / MANUAL 模式
  • 默认上电：总闸关 + AUTO 模式
02

自动模式阈值控制

在 AUTO 模式下，根据传感器实时数据与预设阈值自动控制执行器。

  • 光照 < 阈值（默认 150 lux）→ 开灯；否则关灯
  • 温度 > 阈值（默认 30.0°C）→ 开风扇；否则关风扇
  • 阈值可通过 MQTT 远程修改，NVS 持久化保存
03

RGB 指示灯六态算法

WS2812 RGB 灯珠根据设备状态显示不同动画，优先级从高到低：

  • 严重报警（灯+扇全开）→ 红红绿绿蓝蓝 1200ms
  • 光照报警（灯开）→ 红→绿→蓝 1500ms
  • 温度报警（扇开）→ 红→绿→蓝→灭 2200ms
  • WiFi 断连 → 红→绿→灭 900ms
  • MQTT 断连 → HSV 渐变 2000ms
  • 全部正常 → HSV 渐变 4200ms
04

串口命令控制台

通过 115200bps 串口输入命令，支持多模块共享串口输入的行级分发器。

  • WiFi 命令：SCAN / STATUS / DISCONNECT / RECONNECT / RESET
  • MQTT 命令：MQTT SHOW / SET / CLEAR / RECONNECT
  • RGB 命令：RGB R G B / RGB #RRGGBB / LED OFF
05

LCD 显示布局

0.96 寸 OLED 五栏信息显示，关键运行参数一目了然。

  • 第 1 行：当前模式（AUTO / MANUAL）
  • 第 2 行：光照强度（lux）
  • 第 3 行：温度值（°C）
  • 第 4 行：WiFi + 云端连接状态
  • 第 5 行：灯与风扇开关状态
06

NVS 持久化存储

利用 ESP32 的 Preferences 库（NVS 分区）保存配置参数，掉电不丢失。

  • WiFi 凭据：ssid / pass（命名空间 pct100）
  • MQTT 配置：mqtt_ip / mqtt_port / mqtt_user / mqtt_pass / mqtt_id
  • 阈值参数：light_threshold / temp_threshold
  • 擦写寿命约 10 万次

WiFi

WiFi 配网模块

三种配网模式覆盖从开发调试到生产部署的全场景需求，通过 wifi_mgr.h 顶部的宏切换。

模式 1

STATIC — 静态配网

写死 SSID/PASSWORD 宏，上电自动连接，适合开发调试场景。

  • 宏定义：WIFI_MODE_STATIC (1)
  • 上电直接 WiFi.begin(WIFI_SSID, WIFI_PASSWORD)
  • 连接成功后打印 IP/SSID/RSSI/MAC
  • 同时将凭据写入 Flash
模式 2

SCAN — 扫描配网

异步扫描附近 WiFi，通过串口选择并输入密码，适合现场部署。

  • 宏定义：WIFI_MODE_SCAN (2)
  • 上电自动扫描并打印网络列表
  • 用户选择序号 + 输入密码
  • 连接成功后打印 IP 信息（不写 Flash）
模式 3

SAVED — 保存自动重连（默认）

优先使用 Flash 保存的凭据直接连接，无保存时进入扫描配网，连上后自动保存。

  • 宏定义：WIFI_MODE_SAVED (3)
  • 首次上电 → 扫描配网 → 自动保存
  • 再次上电 → 直接连接（串口无提示）
  • 密码错误 → 20s 超时自动清除旧账号 → 重新扫描
  • 串口 RESET 可清除保存的凭据

MQTT

MQTT 通信模块

设备通过 MQTT 协议与云端 Broker 通信，支持 5 种远程命令与 8 字段状态上报，LWT 遗嘱机制确保设备在线状态实时可靠。

Topic 概览

↑ chemctrl/{id}/status
设备上行状态上报，8 字段 JSON，触发方式：5s 心跳 / 收到 get_status / 命令执行后回包
↓ chemctrl/{id}/command
云端下行命令，支持 set_relay / set_mode / get_status / set_threshold / reboot
💀 chemctrl/{id}/lwt
遗嘱消息，retain + QoS 1，设备离线时自动发布，云端实时感知

MQTT 设备端串口配置命令

命令说明
MQTT SHOW显示 5 项配置 + 连接状态
MQTT SET IP <ip>设置 Broker IP（例: MQTT SET IP your_broker_ip）
MQTT SET PORT <port>设置端口（例: MQTT SET PORT 8081）
MQTT SET USER <user>设置用户名
MQTT SET PASS <pass>设置密码
MQTT SET ID <id>设置设备 ID（例: MQTT SET ID PCT_100_005）
MQTT SET LIGHT_TH <lux>设置光照阈值（例: MQTT SET LIGHT_TH 150）
MQTT SET TEMP_TH <°C>设置温度阈值（例: MQTT SET TEMP_TH 30.0）
MQTT CLEAR恢复 5 项出厂默认 + 写 NVS + 自动重连
MQTT RECONNECT强制断开后重连

💡 调试工具推荐：MQTTX

MQTTX 是 EMQX 出品的桌面 MQTT 客户端，可用于观察设备上报消息、主动下发命令、调试多设备。下载地址： mqttx.app/zh 或 GitHub Releases。 新建连接时填 Host your_broker_ip、Port 8081、Username your_username、Password your_password，Client ID 需与设备不同。
