入门指南

从零开始上手 PCT_100 化工控制实训装置

Quick Start

快速上手

按照以下步骤，在 10 分钟内完成硬件连接、固件烧录和基本功能验证。

1

硬件准备 必备

  • ESP32 / ESP32-C3 开发板 × 1
  • 0.96 寸 SH1106 OLED 显示屏 (I2C: SDA=GPIO4, SCL=GPIO5)
  • DS18B20 温度传感器
  • 光敏电阻模块 (ADC 输入)
  • WS2812 RGB 灯珠 (GPIO0)
  • 2 路继电器模块 (LED=GPIO6, 风扇=GPIO7)
  • KEY1 自锁开关 (GPIO20), KEY2 轻触按键 (GPIO21)
  • USB 数据线 (非充电线) 用于供电与烧录

硬件接线参考 参考

2

安装 Arduino IDE 与 ESP32 支持 必备

  • 下载安装 Arduino IDE
  • 文件 → 首选项 → 附加开发板管理器地址，填入：
    https://espressif.github.io/arduino-esp32/package_esp32_index.json
  • 工具 → 开发板 → 开发板管理器，搜索并安装 esp32
  • 工具 → 开发板 → 选择 ESP32C3 Dev Module
3

安装依赖库 必备

工具 → 管理库，搜索并安装以下库：

  • PubSubClient — MQTT 客户端
  • ArduinoJson — JSON 序列化
  • Adafruit SSD1306 / SH1106 — OLED 驱动
  • Adafruit GFX — 图形库
  • Adafruit NeoPixel — WS2812 驱动
  • OneWire — DS18B20 通信
4

烧录固件 关键

  • 打开 PCT_100.ino 项目文件
  • 确认开发板选择 ESP32C3 Dev Module，Flash 选 4MB
  • 分区方案选择 Default 4MB with spiffs
  • 按住开发板 BOOT 按钮，点击 → 上传按钮
  • 等待烧录完成，松开 BOOT 按钮
  • 打开串口监视器 (115200 baud)，观察启动日志
5

WiFi 配网 必备

默认配网模式为 SAVED (Flash 保存自动重连)：

  • 首次上电 → 串口打印扫描到的 WiFi 列表
  • 输入目标网络的 序号 → 回车
  • 输入 密码 → 回车
  • 连接成功后会打印 IP 地址并自动保存凭据
  • 再次上电自动连接，串口无提示
  • 如需切换网络，串口发送 RESET 清除保存的账号
6

验证基本功能 验证

  • OLED 显示：开机后显示屏应显示模式、光照、温度、网络和继电器状态
  • RGB 灯：开机 4 秒 7 色循环 → WiFi 已连变绿呼吸 / 未连变红呼吸
  • KEY1 总闸：闭合自锁开关 → 系统上电；断开 → 系统断电
  • KEY2 模式切换：短按循环切换手动模式；长按切换自动/手动
  • 自动模式：光照低于阈值自动开灯，温度高于阈值自动开风扇
7

MQTT 远程调试 可选

  • PC 端安装 MQTTX 客户端
  • 新建连接，填写配置信息（参见 产品说明书 → MQTT）
  • 订阅 chemctrl/{设备ID}/status 查看设备上报
  • 向 chemctrl/{设备ID}/command 发送 JSON 命令
  • 常用命令：{"cmd":"get_status"}、{"cmd":"set_relay","relay":3,"value":true}
